# 🧬 Bioinformatics Differential Gene Expression Analysis

## 📊 Project Overview
This data science project applies computational biology techniques to isolate altered genetic biomarkers from clinical expression matrices. Using automated pipelines, we calculate Log2 Fold Changes to identify significantly up-regulated and down-regulated genes.

## 🛠️ Technology Stack
* **Language:** Python 3 (Cloud Environment)
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## 📂 Project Structure & Deliverables
* `*.ipynb`: Core Python data pipeline importing data, normalizing values, and tracking statistical variances.
* `expression_distribution.png`: Frequency distribution plot showcasing the expression shifts across sample groups.

## 🚀 Key Results
The data wrapper successfully isolated structural variations and genomic variances across tissue groups. The calculated fold changes highlight distinct genetic profiles, providing clear insights into transcriptional activity without manual local computing overhead.
